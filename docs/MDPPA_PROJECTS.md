## Repository roles

- **This repository** is the existing technical home for MDPPA industry intelligence and the public cross-project development index.
- **RIDESAFE** retains its own application code, GitHub Pages deployment, and issue history. Do not copy or merge its app source here without a technical migration plan.
- New MDPPA software work can be indexed here after its repository and intended governance are confirmed.

## Public-source and governance safeguards

Both repositories are public. **Never commit** board minutes, private correspondence, contact lists, personal data, unpublished budgets, API keys, access tokens, privileged legal advice, or non-public sponsor arrangements here. Keep those materials in MDPPA-approved private systems.

GitHub Pages sites are demonstrations and should be verified separately before presenting them as deployed production tools. Human review is required for compliance interpretations, counterfeit allegations, and any external communications. Nothing in this index authorizes email sending or publication on behalf of MDPPA.
